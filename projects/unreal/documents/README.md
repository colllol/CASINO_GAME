# Unreal surface

Owns Unreal C++, Blueprint integration, input, camera, character, world partitioning,
gameplay framework, replication, and dedicated-server targets. Server authority is
required for currency, inventory, quest rewards, casino outcomes, crime state, and
ownership.

## Phase 0 documents

- `unreal-architecture-mvp.md`: project shape, C++/Blueprint boundary, dedicated-server
  topology, authority, camera transition, asset pipeline, CI entry points, and multiplayer
  verification plan.

This surface is documentation-only until the Owner approves Decision 0001 and the Phase 1
child ticket. Build and runtime commands in the architecture document are proposed entry
points; they are not evidence of an existing Unreal project.
